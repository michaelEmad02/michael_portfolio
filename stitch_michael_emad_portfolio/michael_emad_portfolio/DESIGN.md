## Brand & Style

Blends futuristic geometric display typography with technical monospaced body copy to create a bold, high-impact digital presence for a cutting-edge Flutter developer. The design language is built around uncompromising technical precision, high-contrast structural layouts, and deep immersive states designed to showcase complex mobile applications and clean code architecture.

## Colors

The palette relies on deep, immersive dark backgrounds paired with high-voltage electric cyan and indigo accents. This system commands attention while reducing visual fatigue for developers and technical recruiters reviewing portfolio projects.

## Typography

Typography establishes an immediate technical authority. Futuristic geometric headers command spatial presence, while precise monospaced body copy mimics the IDE environment, reinforcing the developer identity.

## Layout & Spacing

A fluid grid system combined with strict 8px/4px base-2 spacing increments. Layouts adapt dynamically from single-column mobile views to multi-column desktop bento grids showcasing Flutter packages, state management architecture, and live app previews.

## Elevation & Depth

Depth is achieved through tonal surface layering combined with low-opacity cyber-cyan borders (`#38BDF8` at 15% alpha) and subtle ambient glows. Avoid heavy drop shadows in favor of crisp, razor-thin outlines that communicate precision and high performance.

## Shapes

Strictly enforced soft roundedness (`1`). Elements feature a tight `0.25rem` radius for standard containers and buttons, scaling up to `0.5rem` and `0.75rem` for major project cards and modal windows. This creates a restrained, modern geometry.

## Components

- **Buttons:** High-impact primary action buttons use solid cyan (`#38BDF8`) backgrounds with dark text, while secondary actions use ghost borders with translucent hover states.
- **Chips:** Monospaced technology tags (e.g., "Bloc", "Riverpod", "Firebase") styled with micro-padding and faint indigo backplates.
- **Lists:** Clean key-value metrics and project milestone logs utilizing monospaced alignment.
- **Input Fields:** Terminal-inspired inputs featuring distinct focus rings and monospace text for project inquiry forms.
- **Cards:** Bento-style project display cards featuring dark surface tones, structural borders, and subtle gradient corner accents.
